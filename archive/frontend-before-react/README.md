# Entry HTML sebelum React

`index.html` adalah salinan byte-for-byte dari `frontend/index.html` sebelum setup React.
SHA-256 dapat dibandingkan dengan `git show b4524df:frontend/index.html`.

`frontend/test.html` dan seluruh `frontend/layanan-publik/` tetap berada di lokasi
semula, tanpa perubahan. Salinan ini bukan halaman aplikasi yang dipublikasikan.
